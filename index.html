Blog and learning notes

What is a CPU cache?

Date: 10 March 2026

A CPU cache is a small and very fast memory inside the processor. It stores copies of data that the CPU uses often, so the CPU does not need to wait for slower main memory. This helps programs run faster and improves performance.

Intro to normalisation in databases

Date: 10 March 2026

Normalisation is the process of organising database tables so that data is not duplicated unnecessarily. It helps keep data consistent and makes a database easier to maintain. This is important when designing reliable data-driven systems.

What is an HTTP request?

Date: 10 March 2026

When I type a website address into my browser and press Enter, my computer sends an HTTP request to a web server. This request asks for a specific resource, such as a web page or an image. The server then sends back an HTTP response, and the browser displays the content.
