Blog and learning notes

What is a CPU cache?

Date: 10 March 2026

A CPU cache is a small and very fast memory inside the processor. It stores copies of data that the CPU uses often, so the CPU does not need to wait for slower main memory.

Intro to normalisation in databases

Date: 10 March 2026

Normalisation organises database tables so data is not duplicated unnecessarily. It keeps data consistent and easier to maintain.

What is an HTTP request?

Date: 10 March 2026

When a browser requests a webpage from a server it sends an HTTP request. The server responds with the page content.
